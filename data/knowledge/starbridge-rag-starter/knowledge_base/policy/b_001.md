# 当前套餐功能与容量

## 适用范围
本政策适用于2026-09-01及之后的当前套餐咨询。历史日期应根据当时有效的政策处理，不得把本文件直接用于2026-08-31及以前的事件。

## 套餐对比
| 项目 | 团队版 | 企业版 |
| --- | ---: | ---: |
| 每组织成员上限 | 20名 | 200名 |
| 每组织项目上限 | 10个 | 100个 |
| 任务、评论、附件 | 支持 | 支持 |
| CSV导入导出 | 支持 | 支持 |
| 邮箱密码登录 | 支持 | 支持 |
| SSO | 不支持 | 支持 |
| 最近90天审计日志 | 不支持 | 支持 |

## 统计口径
成员数包括组织管理员、项目管理员和普通成员。项目归档后仍占用项目容量，只有删除项目后才释放相应数量。加入组织和加入项目是不同操作，成员额度只表示可以加入组织的人数，不自动授予项目访问权限。
